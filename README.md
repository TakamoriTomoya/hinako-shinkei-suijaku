# ひなこの神経衰弱

ひなこの写真で遊ぶ神経衰弱。仕様は [doc/SPEC.md](doc/SPEC.md)。

あそぶ: https://hinako-shinkei-suijaku.vercel.app
(`main` に push すると Vercel に自動でデプロイされる)

```sh
npm install
npm run dev    # 開発サーバー
npm test       # ルールのテスト
npm run build
```

## 写真について

このリポジトリの写真（`public/images/` など）は実在の人物を撮影したものです。
写真の著作権・肖像権は撮影者と被写体本人にあります。
このゲームで遊ぶ以外の目的での利用・転載・加工・再配布はしないでください。
